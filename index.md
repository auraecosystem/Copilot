<p>With Copilot cloud agent, GitHub Copilot can work independently in the background to complete tasks, just like a human developer.</p>
<p>Copilot cloud agent can:</p><ul>
<li>Research a repository</li>
<li>Create implementation plans</li>
<li>Fix bugs</li>
<li>Implement incremental new features</li>
<li>Improve test coverage</li>
<li>Update documentation</li>
<li>Address technical debt</li>
<li>Resolve merge conflicts</li>
</ul>
<p>When you delegate tasks to Copilot cloud agent, you can:</p>
<ul>
<li>Use the agents panel or other agents entry points on GitHub.com to have Copilot research, plan, and make code changes on a branch, then iterate before creating a pull request. You can also specify in your prompt that you want a pull request created right away. See <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/research-plan-iterate">Research, plan, and iterate on code changes with Copilot cloud agent</a>.</li>
<li>Ask Copilot to open a new pull request from other entry points, including GitHub Issues and Visual Studio Code. See <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/start-copilot-sessions">Starting GitHub Copilot sessions</a>.</li>
<li>Mention <code>@copilot</code> in a comment on an existing pull request to ask it to make changes. See <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/make-changes-to-an-existing-pr">Review output from Copilot</a>.</li>
<li>Assign security alerts to Copilot from security campaigns. See <a href="/en/enterprise-cloud@latest/code-security/code-scanning/managing-code-scanning-alerts/fixing-alerts-in-security-campaign#assigning-alerts-to-copilot-cloud-agent">Fixing alerts in a security campaign</a>.</li>
</ul>
<p>Copilot cloud agent will evaluate the task it has been assigned based on the prompt you give it.</p>
<p>While working on a coding task, Copilot cloud agent has access to its own ephemeral development environment, powered by GitHub Actions, where it can explore your code, make changes, execute automated tests and linters and more.</p>

<h3 id="benefits-over-traditional-ai-workflows" tabindex="-1"><a class="heading-link" href="#benefits-over-traditional-ai-workflows">Benefits over traditional AI workflows<span class="heading-link-symbol" aria-hidden="true"></span></a></h3>
<p>When used effectively, Copilot cloud agent offers productivity benefits over traditional AI assistants in IDEs:</p>
<ul>
<li>
<p>With <strong>AI assistants in IDEs</strong>, coding happens <strong>locally</strong>. Individual developers pair in <strong>synchronous</strong> sessions with the AI assistant. Decisions made during the session are <strong>untracked</strong> and lost to time unless committed. Although the assistant helps write code, the developer still has a lot of <strong>manual steps</strong> to do: create the branch, write commit messages, push the changes, open the PR, write the PR description, get a review, iterate in the IDE, and repeat. These steps take time and effort that may be hard to justify for simple or routine issues.</p>
</li>
<li>
<p>With <strong>Copilot cloud agent</strong>, all coding and iterating happens <strong>on GitHub</strong>. You can ask Copilot to <strong>research</strong> a repository, <strong>create a plan</strong>, and <strong>make code changes</strong> on a branch—all before opening a pull request. You can create multiple custom agents that specialize in different types of tasks. Copilot <strong>automates</strong> branch creation, commit message writing, and pushing. Developers let the agents <strong>work in the background</strong> and then chooses to <strong>create a pull request</strong> when ready. Working on GitHub adds <strong>transparency</strong>, with every step happening in a commit and being viewable in logs, and opens up <strong>collaboration</strong> opportunities for the entire team.</p>
</li>
</ul>
<h2 id="copilot-cloud-agent-versus-agent-mode" tabindex="-1"><a class="heading-link" href="#copilot-cloud-agent-versus-agent-mode">Copilot cloud agent versus agent mode<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Copilot cloud agent is distinct from the "agent mode" feature available in your IDE. Copilot cloud agent works autonomously in a GitHub Actions-powered environment to complete development tasks assigned through GitHub issues or GitHub Copilot Chat prompts. It can research a repository, create a plan, make code changes on a branch, and optionally open a pull request. In contrast, agent mode in your IDE makes autonomous edits directly in your local development environment. For more information about agent mode, see <a href="/en/enterprise-cloud@latest/copilot/using-github-copilot/copilot-chat/asking-github-copilot-questions-in-your-ide">Asking GitHub Copilot questions in your IDE</a>.</p>
<h2 id="streamlining-software-development-with-copilot-cloud-agent" tabindex="-1"><a class="heading-link" href="#streamlining-software-development-with-copilot-cloud-agent">Streamlining software development with Copilot cloud agent<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Assigning tasks to Copilot cloud agent can enhance your software development workflow.</p>
<p>For example, you can assign Copilot cloud agent to straightforward issues on your backlog by selecting "Copilot" as the assignee. This allows you to spend less time on these issues and more time on more complex or interesting work, or work that requires a high degree of creative thinking. Copilot cloud agent can work on "nice to have" issues that improve the quality of your codebase or product, but often remain on the backlog while you focus on more urgent work.</p>
<p>Having Copilot cloud agent as an additional coding resource also allows you to start tasks that you might not have otherwise started due to lack of resources. For example, you might create issues to refactor code or add more logging, and then immediately assign these to Copilot.</p>
<p>You can also use Copilot cloud agent to research a repository and create a plan before any code is written, helping you understand how a codebase works or agree on an approach before committing to changes. See <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/research-plan-iterate">Research, plan, and iterate on code changes with Copilot cloud agent</a>.</p>
<p>Copilot cloud agent can start a task, which you then pick up and continue working on yourself. By assigning the initial work to Copilot, you free up time that you would otherwise have spent doing repetitive tasks, such as setting up the scaffolding for a new project.</p>
<p>You can create specialized custom agents for different tasks. For example, you might create a custom agent specialized for frontend development that focuses on React components and styling, a documentation agent that excels at writing and updating technical documentation, or a testing agent that specializes in generating comprehensive unit tests. Each custom agent can be tailored with specific prompts and tools suited to its particular task.</p>
<h2 id="measuring-pull-request-outcomes-for-copilot-cloud-agent" tabindex="-1"><a class="heading-link" href="#measuring-pull-request-outcomes-for-copilot-cloud-agent">Measuring pull request outcomes for Copilot cloud agent<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Enterprise administrators and organization owners can use Copilot usage metrics to analyze pull request outcomes for pull requests created by Copilot cloud agent.</p>
<p>The Copilot usage metrics APIs include pull request lifecycle metrics such as:</p>
<ul>
<li>The total number of pull requests created and merged</li>
<li>The number of pull requests created by Copilot cloud agent that have been merged</li>
<li>Median time to merge for merged pull requests, including pull requests created by Copilot cloud agent</li>
</ul>
<p>These metrics can help you track adoption of Copilot cloud agent and monitor changes in pull request throughput and time to merge over time. See <a href="/en/enterprise-cloud@latest/copilot/concepts/copilot-usage-metrics/copilot-metrics">GitHub Copilot usage metrics</a>.</p>
<h2 id="integrating-copilot-cloud-agent-with-third-party-tools" tabindex="-1"><a class="heading-link" href="#integrating-copilot-cloud-agent-with-third-party-tools">Integrating Copilot cloud agent with third-party tools<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>You can also invoke Copilot cloud agent from external tools, allowing you to assign tasks to Copilot, provide context, and open pull requests without leaving your workflow. See <a href="/en/enterprise-cloud@latest/copilot/concepts/tools/about-copilot-integrations">About Copilot integrations</a></p>
<h2 id="making-copilot-cloud-agent-available" tabindex="-1"><a class="heading-link" href="#making-copilot-cloud-agent-available">Making Copilot cloud agent available<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Before you can assign tasks to Copilot cloud agent, it must be enabled.</p>
<p>Copilot cloud agent is available with the GitHub Copilot Pro, GitHub Copilot Pro+, GitHub Copilot Business and GitHub Copilot Enterprise plans.</p>
<p>If you are a GitHub Copilot Business or GitHub Copilot Enterprise subscriber, an administrator must enable the relevant policy before you can use the agent.</p>
<p>Repository owners can choose to opt out some or all repositories from Copilot cloud agent.</p>
<p>For more information, see <a href="/en/enterprise-cloud@latest/copilot/concepts/agents/cloud-agent/access-management">Managing access to GitHub Copilot cloud agent</a>.</p>
<h2 id="ai-models-for-copilot-cloud-agent" tabindex="-1"><a class="heading-link" href="#ai-models-for-copilot-cloud-agent">AI models for Copilot cloud agent<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Depending on how you start your Copilot cloud agent task, you may be able to select the model used by Copilot cloud agent. You may find that different models perform better, or provide more useful responses, depending on the type of tasks you give Copilot.</p>
<p>For more information, see <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/changing-the-ai-model">Changing the AI model for GitHub Copilot cloud agent</a>.</p>
<h2 id="enhancing-copilot-cloud-agents-knowledge-of-a-repository" tabindex="-1"><a class="heading-link" href="#enhancing-copilot-cloud-agents-knowledge-of-a-repository">Enhancing Copilot cloud agent's knowledge of a repository<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>The more Copilot cloud agent knows about the code in your repository, the tools you use, and your coding standards and practices, the more effective it will become. There are two ways you can enhance Copilot cloud agent's knowledge of a repository.</p>
<ul>
<li>
<p><strong>Custom instructions</strong></p>
<p>These are short, natural‑language statements that you write and store as one or more files in a repository. If you are the owner of an organization on GitHub you can also define custom instructions in the settings for your organization. For more information, see <a href="/en/enterprise-cloud@latest/copilot/concepts/prompting/response-customization?tool=webui#about-repository-custom-instructions">About customizing GitHub Copilot responses</a>.</p>
</li>
<li>
<p><strong>Copilot Memory</strong> (public preview)</p>
<p>If you have a Copilot Pro or Copilot Pro+ plan, you can enable Copilot Memory. This allows Copilot to store useful details it has worked out for itself about a repository. Copilot cloud agent can then use this information when it is working in that repository. For more information, see <a href="/en/enterprise-cloud@latest/copilot/concepts/agents/copilot-memory">About GitHub Copilot Memory</a>.</p>
</li>
</ul>
<h2 id="copilot-cloud-agent-usage-costs" tabindex="-1"><a class="heading-link" href="#copilot-cloud-agent-usage-costs">Copilot cloud agent usage costs<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Copilot cloud agent uses GitHub Actions minutes and Copilot premium requests.</p>
<p>Within your monthly usage allowance for GitHub Actions and premium requests, you can ask Copilot cloud agent to work on coding tasks without incurring any additional costs.</p>
<p>For more information, see <a href="/en/enterprise-cloud@latest/billing/managing-billing-for-your-products/managing-billing-for-github-copilot/about-billing-for-github-copilot#allowance-usage-for-copilot-cloud-agent">GitHub Copilot licenses</a>.</p>
<h2 id="customizing-copilot-cloud-agent" tabindex="-1"><a class="heading-link" href="#customizing-copilot-cloud-agent">Customizing Copilot cloud agent<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>You can customize Copilot cloud agent in a number of ways:</p>
<ul>
<li><strong>Custom instructions</strong>: Custom instructions allow you to give Copilot additional context on your project and how to build, test and validate its changes. For more information, see <a href="/en/enterprise-cloud@latest/copilot/how-tos/configure-custom-instructions/add-repository-instructions">Adding repository custom instructions for GitHub Copilot</a>.</li>
<li><strong>Model Context Protocol (MCP) servers</strong>: MCP servers allow you to give Copilot access to different data sources and tools. For more information, see <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/extend-cloud-agent-with-mcp">Connect agents to external tools</a>.</li>
<li><strong>Custom agents</strong>: Custom agents allow you to create different specialized versions of Copilot for different tasks. For example, you could customize Copilot to be an expert frontend engineer following your team's guidelines. For more information, see <a href="/en/enterprise-cloud@latest/copilot/concepts/agents/cloud-agent/about-custom-agents">About custom agents</a>.</li>
<li><strong>Hooks</strong>: Hooks allow you to execute custom shell commands at key points during agent execution, enabling you to add validation, logging, security scanning, or workflow automation. For more information, see <a href="/en/enterprise-cloud@latest/copilot/concepts/agents/hooks">About hooks for GitHub Copilot</a>.</li>
<li><strong>Skills</strong>: Skills allow you to enhance the ability of Copilot to perform specialized tasks with instructions, scripts, and resources. For more information, see <a href="/en/enterprise-cloud@latest/copilot/concepts/agents/about-agent-skills">About agent skills</a>.</li>
</ul>
<h2 id="limitations-of-copilot-cloud-agent" tabindex="-1"><a class="heading-link" href="#limitations-of-copilot-cloud-agent">Limitations of Copilot cloud agent<span class="heading-link-symbol" aria-hidden="true"></span></a></h2>
<p>Copilot cloud agent has certain limitations in its software development workflow and compatibility with other features.</p>
<h3 id="limitations-in-copilot-cloud-agents-software-development-workflow" tabindex="-1"><a class="heading-link" href="#limitations-in-copilot-cloud-agents-software-development-workflow">Limitations in Copilot cloud agent's software development workflow<span class="heading-link-symbol" aria-hidden="true"></span></a></h3>
<ul>
<li><strong>Copilot can only make changes in the repository specified when you start a task</strong>. Copilot cannot make changes across multiple repositories in one run.</li>
<li><strong>By default, Copilot can only access context in the repository specified when you start a task</strong>. The Copilot MCP server is configured by default to allow Copilot to access context (for example issues and historic pull requests) in the repository where it is working. You can, however, configure broader access. See <a href="/en/enterprise-cloud@latest/copilot/how-tos/use-copilot-agents/cloud-agent/extend-cloud-agent-with-mcp">Connect agents to external tools</a>.</li>
<li><strong>Copilot can only work on one branch at a time</strong> and can open exactly one pull request to address each task it is assigned.</li>
</ul>
<h3 id="limitations-in-copilot-cloud-agents-compatibility-with-other-features" tabindex="-1"><a class="heading-link" href="#limitations-in-copilot-cloud-agents-compatibility-with-other-features">Limitations in Copilot cloud agent's compatibility with other features<span class="heading-link-symbol" aria-hidden="true"></span></a></h3>
<ul>
<li><strong>Copilot isn't able to comply with certain rules that may be configured for your repository</strong>. If you have configured a ruleset or branch protection rule that isn't compatible with Copilot cloud agent, access to the agent will be blocked. For example, a rule that only allows specific commit authors can prevent Copilot cloud agent from creating or updating pull requests. If the rule is configured using rulesets, you can add Copilot as a bypass actor to enable access. See <a href="/en/enterprise-cloud@latest/repositories/configuring-branches-and-merges-in-your-repository/managing-rulesets/creating-rulesets-for-a-repository#granting-bypass-permissions-for-your-branch-or-tag-ruleset">Creating rulesets for a repository</a>.</li>
<li><strong>Copilot cloud agent doesn't account for content exclusions</strong>. Content exclusions allow administrators to configure Copilot to ignore certain files. When using Copilot cloud agent, Copilot will not ignore these files, and will be able to see and update them. See <a href="/en/enterprise-cloud@latest/copilot/managing-copilot/configuring-and-auditing-content-exclusion/excluding-content-from-github-copilot">Excluding content from GitHub Copilot</a>.</li>
<li><strong>Copilot cloud agent only works with repositories hosted on GitHub</strong>. If your repository is stored using a different code hosting platform, Copilot won't be able to work on it.</li>
</ul>
